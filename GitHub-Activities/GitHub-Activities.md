# GitHub-Based Activities

Complete these activities in order and retain evidence through commits and pull requests.

## Activity 1 – Create and maintain a repository
1. Create a GitHub account (if needed).
2. Create a **public** repository named `Java-Advanced-Learner`.
3. Add a description: `Advanced Java OOP practicals and assignment`.
4. Add this project, including its README.
5. Make an initial commit: `Add repository structure and assignment overview`.

## Activity 2 – Develop an OOP mini-project
Build the Library Management System in `Programming-Answers/10_LibraryManagementMini.java` further:
- Add a `Member` class and member registration.
- Add issue and return operations with validation.
- Use inheritance or interfaces where appropriate.
- Use collections to store books and members.
- Handle invalid IDs and duplicate entries safely.
- Document the class design and sample output.

## Activity 3 – Collaborate using branches and pull requests
1. Create a branch named `feature/library-members`.
2. Implement member registration and commit the change.
3. Push the branch to GitHub.
4. Open a pull request against `main`.
5. Review the changes, add a review comment, and merge the pull request.

## Activity 4 – Exception handling, multithreading, and collections
Study and run programs 6–8. Extend at least one program with input validation and meaningful error handling. Add a separate commit describing the improvement.

## Activity 5 – Peer code review
Review a classmate's Java code. Check naming, access modifiers, validation, exception handling, readability, and test cases. Submit constructive suggestions through a pull request.

## Activity 6 – Documentation and submission
Update the root README with:
- Project objective and features.
- JDK version and run instructions.
- Screenshots or console output.
- OOP concepts used.
- Your name, course, and assignment details (add these yourself).
