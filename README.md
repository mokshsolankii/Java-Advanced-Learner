# Java Advanced Learner – OOP Assignment

Prepared for the **Advanced Learner** category. This repository contains the GitHub-based activities and the additional mandatory assignment: **10 Java programming questions + 10 non-programming OOP questions (hard level)**.

## Repository structure

```text
Java-Advanced-Learner/
├── Programming-Answers/       # 10 Java programs with source code
├── Theory-Answers/            # 10 OOP theory questions with answers
├── GitHub-Activities/         # GitHub tasks and mini-project brief
└── README.md
```

### Compile and run a program

Open a terminal inside `Programming-Answers`. For example:

```bash
javac 01_BankAccountEncapsulation.java
java BankAccountEncapsulation
```

The source files are numbered for assignment organization. Their main classes are package-private so the numbered filenames remain valid Java source filenames. Run the class name shown in the table.

JDK 17 or later is recommended.

## Part B – Non-programming (10)

Open `Theory-Answers` for the 10 hard-level questions and answers, covering:
1. Four pillars of OOP.
2. Method overloading vs. overriding.
3. Dynamic method dispatch.
4. Abstract classes vs. interfaces.
5. Composition vs. inheritance.
6. Checked vs. unchecked exceptions.
7. finally, throw, and throws.
8. Thread lifecycle; start() vs. run().
9. Synchronization and thread safety.
10. ArrayList, LinkedList, HashSet, and HashMap.
