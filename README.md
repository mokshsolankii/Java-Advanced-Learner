# Java Advanced Learner – OOP Assignment

Prepared for the **Advanced Learner** category based on the course activity sheet.

## What's included
- 10 hard-level Java programming questions with sample solutions.
- 10 OOP theory questions with concise answers.
- GitHub activity instructions for repository management, commits, branches, pull requests, and code review.
- Library Management System mini-project brief and starter program.

## Repository structure
```
Java-Advanced-Learner/
├── Programming-Answers/
├── Theory-Answers/
├── GitHub-Activities/
└── README.md
```

## Requirements
- JDK 17 or later
- Java IDE or terminal
- Git and GitHub account

Compile and run a standalone source file:
```bash
javac FileName.java
java ClassName
```

## Assignment checklist
- [ ] Run and understand all 10 programming solutions.
- [ ] Review and personalize all 10 theory answers.
- [ ] Create a feature branch and make meaningful commits.
- [ ] Open a pull request and merge it into `main`.
- [ ] Extend the Library Management System mini-project.
- [ ] Add sample output/screenshots and update the documentation.

Use the solutions as learning references. Test the programs and understand each concept before submitting. Add your own name, course details, explanations, and evidence of execution.
